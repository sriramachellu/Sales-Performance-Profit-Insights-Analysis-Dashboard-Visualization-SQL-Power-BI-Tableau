# 🏗️ ETL Superstore Project

## 📌 Objective
Build a complete ETL pipeline using Python, MySQL, Apache Spark, and Power BI on the Superstore Sales dataset. Focused on data cleaning, transformation, analysis, and visualization.

---

## 🛠 Tools Used

- Python 3.10.11
- Pandas
- Apache Spark 3.5.5 + PySpark
- MySQL
- Power BI Desktop
- Git + GitHub
- Kaggle CLI
